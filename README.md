# My Personal Portfolio

A professional, full-stack portfolio website built to showcase my projects, technical skills, and journey as a developer. This application features a clean, responsive interface and a functional backend for handling user contact inquiries.

## 🚀 Tech Stack
* **Frontend:** React, Vite, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Styling:** Tailwind CSS

## 🛠 Features
* **Project Gallery:** A dynamic showcase of my technical projects.
* **Responsive Layout:** Optimized for all screen sizes from mobile to desktop.
* **Integrated Backend:** A secure contact form that saves inquiries to a MongoDB database.
* **Performance Focused:** Built using Vite for lightning-fast development and deployment.

## 📁 Project Structure
* `/frontend`: Client-side code and UI components.
* `/backend`: Server-side API and database connection logic.

## ⚙️ How to Run Locally
1. **Clone the repo:** `git clone <https://github.com/divyaprakash3311-sketch/portfolio-website/edit/main/README.md>`
2. **Setup:** Add your `MONGO_URI` to a `.env` file in the `/backend` folder.
3. **Install:** Run `npm install` in both the `frontend` and `backend` folders.
4. **Start:** - `npm run dev` in the frontend directory.
   - `node server.js` in the backend directory.
